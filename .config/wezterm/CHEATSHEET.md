# WezTerm Cheatsheet (macOS)

## Global Keymaps

- `CMD +`: increase font size
- `CMD -`: decrease font size
- `CMD 0`: reset font size
- `CTRL+SHIFT+M`: enter copy mode
- `CMD+SHIFT+SPACE`: quick select (words/paths/urls)
- `CMD+SHIFT+Y`: quick select URLs only

## Copy Mode Tutorial

1. Press `CTRL+SHIFT+M`.
2. Move with `h` `j` `k` `l` (`w`/`b`/`e`, `gg`, `G` also work).
3. Press `Space` to start selection.
4. Move cursor to expand selection.
5. Press `y` to copy and exit copy mode.

## Copy Mode Advanced

- `Ctrl+v` (inside copy mode): switch to block selection
- `q` or `Esc`: close copy mode

## Quick Select Tutorial

1. Press `CMD+SHIFT+SPACE`.
2. Type to filter matches.
3. Press `Enter` on the match.

For URL-only selection, use `CMD+SHIFT+Y`.
